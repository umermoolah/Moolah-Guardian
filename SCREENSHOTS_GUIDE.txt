How to capture screenshots on macOS (simple, reliable methods)

Where to save images: Create a folder called `screenshots/` in the project root.
Command to make it:
  mkdir -p screenshots

Option A — iOS Simulator (recommended on macOS)
1) Open iOS Simulator (manually or with command):
   open -a Simulator
2) From project root, run the app in the simulator (pick a device from `flutter devices`):
   flutter run -d <deviceId>
   or to list devices first: flutter devices
3) Navigate in the running app to the screen you want.
4) Take a screenshot using Flutter CLI (while app is running):
   flutter screenshot --out screenshots/01_enter_email_login_normal_ios.png

Alternative iOS screenshot using simctl (if flutter screenshot fails):
   xcrun simctl io booted screenshot screenshots/01_enter_email_login_normal_ios.png

Option B — Android emulator
1) Start an Android emulator (Android Studio AVD) or use flutter emulators:
   flutter emulators
   flutter emulators --launch <emulatorId>
2) Run the app on the emulator:
   flutter run -d <android-device-id>
3) When on the desired screen, use flutter screenshot:
   flutter screenshot --out screenshots/01_enter_email_login_normal_android.png

Or use adb to capture directly:
   adb exec-out screencap -p > screenshots/01_enter_email_login_normal_android.png

Option C — Real device (USB)
1) Connect the device and trust it; confirm with `flutter devices`.
2) Run the app on the device:
   flutter run -d <deviceId>
3) Use flutter screenshot or adb as above (for Android use adb).

Capture workflow tips (simple)
- Always capture the primary, normal view of each screen first (populated with sample data).
- For list screens capture an empty state too (if applicable).
- For multi-step flows (signup, security check) capture each step as a separate image.
- Use the naming convention below so images stay organized.

Naming convention (easy to follow)
- Format: NN_friendly-name_state_platform_resolution.png
- Example: 01_enter_email_login_normal_ios_1170x2532.png
- Friendly name: use underscores for spaces, keep short (1–3 words)
- State: normal / empty / error / list / details
- Platform: ios / android / realdevice

Recommended resolutions
- Use the simulator/emulator native resolution. For Google Docs keep images about 1200 px wide maximum.
- Common choices: iPhone (1170x2532), Android (1080x2400)

How to insert images into Google Docs
1) In Google Docs: Insert -> Image -> Upload from computer (or drag-and-drop the file into the doc).
2) After inserting, set the image layout to "In line" or "Wrap text". Recommended: "In line" and resize width to about 12–14 cm.
3) Add the filename as a caption/text next to the image for traceability.
4) When done, File -> Download -> PDF Document (.pdf)
